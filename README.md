My entry for make.fun's **ai-joke-03** ("Make the AI judge laugh"): a small
Python program (`main.py`, standard library only) that writes one one-liner
about AI coding agents to `/output/entry.txt`.

Run it outside the grader's container with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
